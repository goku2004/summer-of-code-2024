I learnt some terms regarding RL framework which need to be stated first to clarify the problems I faced:
 1. Environment: An RL environment is basically the set of rewards and possible configurations that are achievable during the experiment. 
 2. State: A state defined the configuration that the system is currently in.
 3. Action: It is defined as the step performed to go from one state to another in an RL environment.

What RL wishes to achieve is to perform a certain state of actions and reach certain states in between such that to ensure maximum reward possible in the whole process. A reward is defined for every state possible in the environment. 
One algorithm to maximize the reward is known as the Q-value algorithm. In this we initilaize a Q-value for a state and then perform actions in such a way that these Q-value is maximized. In some environments one possible path could lead to higher value of reward but a lower value of Q-value. This happens when the cost required to perform that actions may be higher. For this reason we use Bellman equation to define our Q-value. A policy is basically the set of action-state pairs that are achievable in the path taken by the agent(model).
